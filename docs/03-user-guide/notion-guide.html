Chapter 1

Notion kya hai — 2 minute mein

Notion ek aisi jagah hai jahan pages aur databases hote hain. Bas do hi cheezein samajhni hain:

📄 Page

Ek khaali kaagaz. Isme likh sakte ho, dusre pages rakh sakte ho. Aapka 🧠 2nd Brain ek page hai.

🗄️ Database

Excel sheet jaisa — par har row khud ek page hai jise khol sakte ho. Tasks, Goals — sab databases hain.

Screen par kya kahan hai

Notion ka layout — sidebar, view tabs, aur database rows
Sabse zaroori concept: VIEWS. Ek hi database ko alag-alag tareeke se dekh sakte ho. ☀️ Due today aur ⚠️ Slipped — dono same Tasks database hain, bas filter alag hai. Kuch delete nahi hota, sirf chhupta hai.

Field bharnaCell pe click karo, type karo. Select fields mein list se chuno

Chapter 3

Pehla setup — 10 minute, ek baar

Test data mat daalo. Ek asli cheez daalo jo aapko sach mein karni hai. System tabhi samajh aayega.

  1. 🎯 Goals kholo → ek goal likho
    Jo is quarter mein sach mein chahiye. Jaise: "Half marathon complete karna"
    Success criteria field zaroor bharo — woh condition jisse pata chale ki goal pura ho gaya. Isko chhoda toh goal kabhi khatam hi nahi hoga.
    Sahi: "21 km, 2:15 se kam" · Galat: "Fit ho jana"
  2. 🚀 Projects kholo → ek project banao
    Goal field pe click karke upar wala goal chuno.
    Definition of done — kaam shuru karne se pehle likho ki khatam kab maanenge. Ye na ho toh project kabhi khatam nahi hota, phailta rehta hai.
  3. ✅ Tasks kholo → 3-5 tasks daalo
    Har task ko Project se jodo. Har task verb se shuru karo — "Plan banana" nahi, "Running plan likhna".
    Energy zaroor set karo: deep shallow admin recovery
  4. 🔁 Habits kholo → ek habit banao
    Goal se jodo. Cadence chuno (daily/weekly).
    Minimum version — sabse zaroori field. Woh chhoti si cheez jo bure din mein bhi ho jaaye aur count ho.
    Habit: "5 km daudna" → Minimum version: "Joote pehen ke 5 minute chalna"
    Yahi ek field aapki habit ko bure hafte mein bachati hai.
  5. Aaj raat ✍️ Journal mein ek entry likho
    Ek field bhi kaafi hai. Bas shuruaat kar do.
Shuruaat mein kitna? Ek goal. Ek project. Paanch tasks. Ek habit. Bas. Pehle din 20 goals daalne se system nahi chalta — woh sabse aam galti hai.
Chapter 4

Roz ka routine — 7 minute

"Why it slipped" itna important kyun hai?

Kyunki hafte ke ant mein aap yeh column padhoge. Aur agar ek hi wajah teen baar dikhi — jaise "meeting mein time nikal gaya" — toh problem aapki discipline nahi hai. Problem system mein hai. Aur system theek kiya ja sakta hai; khud ko kosne se kuch nahi hota.

Aisa likhoAisa mat likho
"3 baje tak meetings thi, deep work ka time hi nahi bacha""Busy tha"
"Task bahut bada tha, shuru hi nahi kar paya""Aalas aa gaya"
"Sharma ji ka reply nahi aaya""Blocked"

Habit Log kaise bharein

☑️ Habit Log → ☑️ Today view → + New → Habit chuno, Date aaj ki, aur Outcome set karo:

OutcomeKab lagana hai
metPoora ho gaya
partialSirf minimum version hua — ye bhi safalta hai, streak nahi tootegi
missedNahi hua. Note mein wajah likho
pausedBimari, safar. Miss count nahi hoga
Chapter 5

Hafte mein ek baar — 20 minute

Roz ka kaam cheezein organise karta hai. Sirf review hi disha badalta hai. Isliye yeh 20 minute sabse zyada value dete hain.

  1. Tasks → ⚠️ Slipped view kholo
    "Why it slipped" column padho. Koi pattern dikh raha hai?
  2. Goals → 🎯 Active view kholo
    Har goal ke neeche kuch hila? Nahi hila toh honestly maano.
  3. Projects → 🚀 Board kholo
    14 din se koi task complete nahi hua? Woh project stalled hai. Uska matlab hai koi decision pending hai.
  4. 📊 Reviews mein nayi entry banao
    Type = weekly, period ki dates daalo.

Review mein kya likhna hai

FieldKya likhna hai
What movedKya sach mein aage badha
What slippedSlipped view se pattern uthao. Yeh ekmatra section hai jo yaadash pe nahi, sabooton pe bana hai.
Honest assessmentKya main sahi cheez pe kaam kar raha tha? Isme koi data nahi hai — sirf sachai. Bina iske review sirf report hai.
ActionsAgle hafte kya badloge. 1-2 cheez, zyada nahi
Goal chhodna failure nahi hai. Agar koi goal 60 din se hila nahi, use dormant ya abandoned mark karo aur Why abandoned bharo.

Chhode hue goals ka record is system ka sabse keemti data ban jaayega — kyunki agle saal aap wahi goal dobara set karne se pehle padh sakoge ki pichhli baar kyun chhoda tha.

Mahine mein ek baar (60 min)

Wahi process, par events nahi — trends dekho. Char sawaal:

Kya goals abhi bhi sahi hain?

3 mahine pehle jo zaroori laga tha, kya ab bhi hai?

Kaunsa area chhoot raha hai?

Goals ko Area se group karo. Koi column khaali hai?

Energy ka pattern kya hai?

Journal mein "depleted" kitni baar aaya? Load sustainable hai?

Kya cheez use hi nahi ho rahi?

Jo field ya database ek mahine se khaali hai — hata do.

Paanch niyam

1Ek hi Inbox. Sab kuch wahin se aata hai.
2Capture ke waqt sochna nahi. Routing raat ko hoti hai.
3Har Project ka ek Goal. Bina Goal ka project — ya toh Goal missing hai, ya project bekaar.
4Progress khud mat likho. Woh neeche ke kaam se apne aap banta hai.
5Chhodna bhi ek jawab hai. Abandoned goal ka record rakhna faayde ka hai.

Jab system chhootne lage

3 din miss ho gaye? Backlog clear karne ki koshish mat karo. Aaj se shuru karo. Yeh system aise hi bana hai — pichhla hafta pura kiye bina bhi weekly review ho sakta hai.

Inbox mein 40 items? Sab delete kar do. 14 din se pada item ek backlog nahi hai — woh saboot hai ki woh cheez maayne nahi rakhti thi.
